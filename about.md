# dim5lBOT

A frame-based Geometry Dash macro recorder and replay player.

## Controls

- Open the pause menu and press **dim5lBOT**.
- **Record** clears the current macro and starts recording.
- **Stop** stops recording or playback.
- **Play** restarts the level and replays the current macro.
- **Save** writes the current macro to `geode/mods/lxdim5lxl.dim5lbot/macros/last-replay.json`.
- **Load** loads that file.
- **Clear** removes the macro currently held in memory.

Macros store the frame, press/release state, button, and player for every input.
